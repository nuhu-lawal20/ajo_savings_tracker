### Decisions Made
- App name: Alajo (Yoruba/Hausa — authentic Nigerian)
- Hosting: Vercel (NOT Netlify — new Netlify only gives ~15GB bandwidth via credits)
- Backend: Supabase Edge Functions (co-located with DB, 500k free invocations)
- Database: Supabase PostgreSQL (DB + Auth + Realtime + Storage in one free tier)
- Payments: Paystack test mode (Nigerian-context, free, full API)
- AI: Rule-based Trust Score (no API cost, runs in pg_cron)
- PWA: Offline-first with Dexie.js + @ducanh2912/next-pwa
- Rate limiting: Upstash Redis (HTTP-based, works in Vercel Edge middleware)
- Email: Resend (3k/mo free, React Email templates)
- Cron: Supabase pg_cron (native, no network latency)
- Push notifications: OneSignal (10k subscribers free)
- Submission link: GitHub repo URL (not deployed URL) + separate demo video URL

### Key Insight — Netlify vs Vercel
New Netlify accounts (post Sept 2025) run on credit system:
300 credits / 20 credits per GB = only 15 GB bandwidth
Each deploy = 15 credits = only 20 deploys free
Vercel: 100 GB bandwidth flat + 6000 build minutes = clear winner

### Security Architecture (10 Layers)
L1 Zod validation, L2 OTP auth, L3 JWT sessions,
L4 RLS at DB level, L5 Upstash rate limits, L6 HMAC webhooks,
L7 Idempotency keys, L8 Env vault secrets, L9 HTTP headers, L10 CORS
